# Explodely Affiliate Setup

## Goal

Use Explodely as an affiliate channel only after your affiliate account, approved offer, tracking link, and payout details are configured.

## Workflow

1. Select an offer you are authorized to promote.
2. Copy the platform-generated affiliate link rather than constructing one manually.
3. Put that link behind the relevant CTA on your landing page.
4. Use campaign/sub-ID tracking when supported so you know which traffic converts.
5. Test the full click path.
6. Confirm conversions inside the affiliate dashboard before scaling traffic.

## ISN / webhook use

An Instant Sales Notification or webhook can trigger legitimate downstream actions after a recorded event—for example logging a conversion, updating analytics, or starting an allowed customer workflow. Protect webhook endpoints, validate incoming events, and never treat an unverified request as proof of payment.

{% hint style="info" %}
An ISN listener helps automate event handling; it does not itself generate sales. Traffic, an offer, and conversions still have to exist.
{% endhint %}
