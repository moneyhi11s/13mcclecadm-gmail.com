# Marketing Automation

## What to automate

* Scheduled content publishing
* Permission-based email sequences
* Lead routing and tagging
* Conversion/event logging
* Campaign reporting
* Broken-link checks
* Customer onboarding for products you control

## Example workflow

**Visitor → lead form → consent recorded → welcome email → useful follow-up → relevant offer → conversion event → analytics dashboard**

## Guardrails

Use platform-approved APIs/integrations, respect unsubscribe requests, rate limits, affiliate terms, and privacy rules. Keep credentials in secret/environment storage rather than documentation or source code.

{% hint style="warning" %}
Never place PayPal passwords, API secrets, webhook secrets, private keys, or account recovery information in this GitBook.
